# Tauri v2 — Cómo añadir un comando nuevo

Cada vez que añades un comando Rust nuevo hay que tocas **3 archivos**. Si falta cualquiera de los tres, sale el error `Command not found` o `Permission not found`.

---

## Los 3 pasos

### 1. Implementar el comando en Rust

En el archivo `.rs` correspondiente (p.ej. `src-tauri/src/schema.rs`):

```rust
#[tauri::command]
pub async fn mi_comando(
    state: State<'_, AppState>,
    connection_id: Uuid,
    // ...parámetros
) -> Result<TipoRetorno, String> {
    // implementación
}
```

### 2. Registrar el comando en `lib.rs`

En `src-tauri/src/lib.rs`, dentro de `.invoke_handler(tauri::generate_handler![...])`:

```rust
crate::schema::mi_comando,
```

### 3. Declarar el permiso

#### 3a. En `src-tauri/permissions/autogenerated.toml`

Añadir al final (o junto a comandos similares):

```toml
[[permission]]
identifier = "allow-mi-comando"
description = "Descripción de lo que hace"
commands.allow = ["mi_comando"]
```

> El `identifier` usa guiones (`-`), el nombre en `commands.allow` usa guiones bajos (`_`).

#### 3b. En `src-tauri/capabilities/default.json`

Añadir el identifier al array `permissions`:

```json
"allow-mi-comando"
```

---

## Resumen rápido

| Archivo | Qué poner |
|---|---|
| `src-tauri/src/*.rs` | `#[tauri::command] pub async fn mi_comando(...)` |
| `src-tauri/src/lib.rs` | `crate::modulo::mi_comando,` en `generate_handler!` |
| `src-tauri/permissions/autogenerated.toml` | Bloque `[[permission]]` con `identifier` y `commands.allow` |
| `src-tauri/capabilities/default.json` | `"allow-mi-comando"` en el array `permissions` |

---

## Errores comunes

| Error | Causa | Solución |
|---|---|---|
| `Command not found` en runtime | Falta en `capabilities/default.json` o en `generate_handler!` | Añadir el permiso y/o registrar el comando |
| `Permission allow-X not found` al compilar | Falta el bloque en `permissions/autogenerated.toml` | Añadir el `[[permission]]` correspondiente |
| El comando no recibe parámetros | Nombre incorrecto: frontend usa camelCase, Rust usa snake_case (Tauri convierte automáticamente) | Verificar que `connectionId` en JS → `connection_id` en Rust |

---

## Ejemplo real: `drop_database`

```
src-tauri/src/schema.rs          → fn drop_database(...)
src-tauri/src/lib.rs             → crate::schema::drop_database,
permissions/autogenerated.toml   → identifier = "allow-drop-database" / commands.allow = ["drop_database"]
capabilities/default.json        → "allow-drop-database"
```
